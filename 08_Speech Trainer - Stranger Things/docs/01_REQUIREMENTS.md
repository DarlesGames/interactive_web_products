# Требования к продукту v1.0

## Пользователь и цель
Обучающийся русскому языку как иностранному, уровень А2. Тренирует спонтанные вопросы, уточнения, гипотезы, причинные связи. Вместо заученного диалога — самостоятельное расследование.

## MVP
1. Главная: название «Очень странные дела», правила, «Начать расследование».
2. Дело №001: завязка «Сообщение из пустой комнаты», **без** разгадки.
3. Выбор доступного свидетеля из пятерых: Аня (администратор), Максим (программист), Лена (фотограф), Илья (бариста), София (новый сотрудник).
4. Свободные вопросы в текстовом поле и через микрофон; распознанную речь можно отредактировать; нет готового обязательного списка вопросов.
5. Речь → текст → нормализация/словарь → интент + сущности/отношения → поиск факта → проверка `knownBy`/условий раскрытия → ответ свидетеля.
6. Четыре основных кода: `YES`, `NO`, `IRRELEVANT`, `UNKNOWN`. Не путать непонимание с несущественной информацией.
7. Короткий естественный ответ персонажа по-русски на уровне A2. Не нужно использовать ИИ.
8. Счётчик принятых вопросов, подсказки автоматически после 3, 6, 9 вопросов, каждая один раз; вручную — по кнопке без дублей.
9. «Моя версия» — голос/текст, проверка 4 частей: человек, цель, способ попадания в комнату, причина сообщения.
10. При верной версии: показать разгадку, число вопросов, подсказки, попытки, разнообразие вопросов, краткую обратную связь.
11. Отказ микрофона / отсутствие Web Speech API не блокируют прохождение.
12. Без базы данных/сервера/авторизации/платных моделей для первой демонстрации.

## Границы
- Не обещать правильность разбора любого русского предложения, морфологический анализ через мини-словарь ограничен.
- Не показывать автоматически грамматические оценки как объективные; обратная связь по типам действий только по надёжно классифицированным вопросам.
- Не делать кабинет преподавателя, рейтинги, редактор историй, оплату, запись аудио на сервер.
- В первой версии **одно законченное дело**; история №002 не обязательна.

## Измеримые критерии
- Один запуск без ведущего от главной страницы до разгадки.
- Все 5 персонажей доступны для выбора, смены и повторного обращения; ответы не копируют чужие знания.
- При неподтверждённом/неоднозначном факте — `UNKNOWN`/«Я не знаю», но никогда уверенное неправдивое YES/NO.
- Неизвестные вопросы не считаются успешно понятыми, но засчитываются в число отправленных вопросов.
- За 3/6/9 принятых вопросов появляется соответствующая ещё не открытая подсказка.
- Можно представить неполную версию и получить указание на недостающий элемент, не раскрыв всю разгадку.
- Ручной ввод работает независимо от состояния микрофона.

## Неизвестные требования
Не указаны: точный стиль интерфейса, озвучка персонажей, время раунда, обязательное сохранение прогресса, способ преподавательской проверки, точные секретные реплики каждого героя. Не додумывать как согласованные функции.
