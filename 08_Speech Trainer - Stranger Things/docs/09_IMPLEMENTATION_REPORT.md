# Перенос в «Очень странные дела»: аудит и проверка

Дата: 30 октября 2026. Запрос пользователя включал аудит и затем реализацию пунктов миграции №6–9 одним сообщением. Аудит сообщён до изменений; переход к реализации выполнен в пределах явно перечисленного запроса. Публикация и создание Git-репозитория не выполнялись.

## Аудит до правок

В корне находились новая документация, `data/cases/case-001.json` и ручной тест-план. Прежнее приложение уже было сохранено пользователем в `old/`: HTML/CSS/JS, ES-модули, без npm-зависимостей, сборки, backend и БД. Активного корневого `index.html` не было. Git-метаданных в корне не обнаружено; коммит или ветка не создавались согласно ранее установленному запрету пользователя создавать репозиторий.

Точки входа старой версии: `old/index.html`, `old/src/app.js`. Экраны: старт с Максимом, чат с подсказками тем, паспорт знакомства. Чистый старый движок: normalize/classify/dialogue/score/session. Голос: `old/src/adapters/speech.js` и `old/src/ui/speech-input.js`, `ru-RU`, предварительный текст отдельно, итоговый в редактируемый черновик, ручная отправка, безопасные ошибки и отмена. Старый сервер: `old/tools/serve.mjs`. До правок архивные **122 теста прошли**.

Переиспользованы базовая вёрстка, карточки, адаптивный CSS, лента сообщений, клавиатурное поведение формы, Web Speech адаптер и статический HTTP-сервер. Заменены активные экраны, продуктовые тексты, данные, классификация знакомств, персональные сессии и оценка 0–5. Архив целиком сохранён, массового удаления исходников нет.

## Изменено

- Активные точки входа: `index.html`, `src/app.js`; ресурсы относительные, `.nojekyll` сохранён для статического размещения.
- Главная, завязка №001, пять карточек с ролями и подтверждёнными публичными описаниями, общий экран расследования, свободная версия и финал. Инициалы вместо внешних изображений.
- Данные загружаются из JSON дела. Публичная проекция `src/core/presentation.js` исключает solution, aliases, факты и матрицу знаний из модели начальных экранов. В DOM не вставляется весь JSON.
- Чистые модули: `normalize.js`, `parseQuestion.js`, `storyEngine.js`, `hints.js`, `state.js`, `solution.js`. Ограниченный словарь русских форм сохраняет отрицание, время, имена и отличие ноутбука от компьютера.
- Факт сопоставляется по субъекту, действию и объекту с проверкой временных и лишних уточнений; неоднозначность и неразрешённые местоимения дают UNKNOWN. Отсутствие факта не считается ложью. Каждый ответ проходит `knownBy` и явно заданный `revealPolicy`.
- Значения YES/NO учитывают отрицание, а реплики остаются полными и недвусмысленными. Например, на «Ты не отправлял сообщение?» у Максима: логический YES и «Нет, я его не отправлял». Чужому свидетелю этот ответ недоступен.
- Уникальные вопросы, глобальный протокол с witnessId, известные улики, подсказки 3/6/9 и ручная выдача без дублей. Пустой ввод и дубли request ID не увеличивают статистику. У каждого свидетеля свой черновик; местоименный контекст при переключении очищается.
- Версия проверяет четыре отношения, поддерживает неполный ответ, неизвестный текст и явные противоречия. Список ключевых слов не становится правильным решением. Полная разгадка показывается только при CORRECT; сброс подтверждается.
- Голосовой UI адаптирован для вопросов и версии; смена свидетеля и переход экрана отменяют захват, предварительные и поздние результаты не меняют следующий экран.

1. В исходной таблице ровно 10 фактов. Для ключа у Ани, родства Софии и Марины, копирования файлов и дополнительных деталей **нет подтверждённой матрицы knownBy**. Они не превращены в ответы свидетелей. Прохождение UI до финала и проверка готовой версии работают, но самостоятельная доказуемая разгадка всех четырёх элементов из текущей базы не гарантирована. Нужна редакторская матрица знаний; пробел зафиксирован в `docs/08_OPEN_ISSUES.md` и не закрывался выдумкой.

3. Не заданы пороги откровенности Софии. Известные ей 4 факта доступны по прямому вопросу, дополнительные сведения не открываются по придуманному числу вопросов. WITHHELD проверен только на явно установленном флаге тестовой конфигурации.

5. Мини-словарь и проверка отношений не являются универсальным пониманием русского. Оценки грамматики или произношения нет. Для дополнительных формулировок возможен UNKNOWN.
6. Настоящий микрофон, системный диалог разрешений, внешняя служба распознавания, физическая мобильная клавиатура и реальный GitHub Pages не проверялись. Голос проверялся на управляемых событиях; ни аудио, ни реплики на собственный сервер не отправляются.
