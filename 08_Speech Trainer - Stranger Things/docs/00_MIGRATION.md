# Миграция: от «Быстрых свиданий» к «Очень странным делам»

## Исходная точка
Пользователь сообщил: старый запрос №4 реализован. Исходники существующего репозитория не переданы в этот пакет. Следовательно, **нельзя угадывать**, какие файлы, классы и функции уже существуют. Пункт №5 новой серии — инвентаризация без правок.

## Матрица миграции
| Старый элемент | Новое поведение | Стратегия |
|---|---|---|
| «Быстрые свидания», знакомство | «Очень странные дела», расследование | Заменить продуктовый текст и маршруты после аудита |
| Пять собеседников для свиданий | Пять свидетелей одного дела | Сохранить компонент выбора, заменить данные/роли |
| Секрет каждого знакомства | Общая загадка, разные знания и условно скрываемые сведения | Перестроить модели данных |
| Персональная коммуникативная миссия | Найти 4 элемента разгадки | Заменить оценку и экран финала |
| Интенты знакомства | Вопросы о субъекте, действии, объекте, месте, времени, причине | Заменить/расширить распознаватель |
| Лента диалога | Лента вопросов и ответов по свидетелям | По возможности переиспользовать |
| Голосовой и ручной ввод | То же, `ru-RU`, исправляемый распознанный текст | Переиспользовать после тестов |
| Сценарные ответы | Реакции только на канонические факты дела | Убрать контент свиданий, общий движок оставить по возможности |
| Рейтинг знакомства 5 критериев | Счётчик вопросов, подсказки 3/6/9, проверка версии и статистика | Заменить |
| Заготовки старого `maxim.sample.json` | `data/cases/case-001.json` | Старый JSON не использовать как источник истины |

## Что необходимо сохранить, если работает
Каркас приложения, стили, адаптивность, компоненты микрофона и ввода, история сообщений, обработка ошибок, конфигурация деплоя, полезные тесты и утилиты. Не сохранять смысловую логику знакомств только потому, что она работает.

## Минимальный порядок перехода
1. **№5 Аудит без правок:** файлы, стек, интерфейс, состояние после запроса №4, риски.
2. **№6 Каркас расследования:** переименовать, заменить экраны и навигацию, не уничтожая ввод.
3. **№7 Контент:** пять свидетелей, фактология дела №001, карточки, отдельные доступные сведения.
4. **№8 Движок:** нормализация, запрос к фактам, проверка осведомлённости, логические статусы, реплики.
5. **№9 Игровой цикл:** счётчик вопросов, подсказки, переходы между свидетелями, «Моя версия».
6. **№10 Голос, тесты и GitHub Pages:** регрессия и публикация.

## Страховка
Перед переносом сделать Git-коммит (или отдельную ветку) старой рабочей версии. Запрос №5 может дать указания по безопасной миграции, но **не** должен менять код. Никогда не удалять целиком `src` только из-за смены продукта. После каждого этапа проверять запуск и `git diff`.

## Условия блокировки
- Отсутствует конкретный факт → не создавать его.
- Факт известен по общей разгадке, но неизвестно, знает ли его свидетель → не превращать в его уверенную реплику.
- Сюжет противоречит самому себе → зафиксировать в `docs/08_OPEN_ISSUES.md`, не придумывать решение.
