# Проверка голоса и правил дела №001

Дата: 30 октября 2026. Основание: `docs/06_TESTING.md`, `tests/case-001-manual.md`, текущий запрос пользователя. Без новых зависимостей, внешнего ИИ, дополнительных API и новых сюжетных фактов. Репозиторий и публикация не создавались.

## Изменено

Переиспользован существующий Web Speech адаптер: `ru-RU`, запуск по нажатию, промежуточный текст только для просмотра, итоговый текст в редактируемом поле, отправка вручную. Для стандартного и префиксного API добавлены браузерные регрессии. Исправлено состояние адаптера после `dispose`: захват завершён, `active=false`, очищены тексты. При отказе доступа, ошибке сети, отсутствии API и поздних событиях остаётся рабочий текстовый путь.

Исправлены локальные правила без изменения JSON истории:

- Сохранена исходная словоформа имени: «Илью видела София» больше не превращается в «Илья видел Софию». Допустимая перестановка «Софию у входа видел Илья» продолжает работать.
- Местоимения согласуются с родом участника и последним названием объекта: «снимок — его», «фотография — её». Однозначный многословный объект сохраняется в контексте; при смене свидетеля контекст очищается.
- Добавлены проверенные формы А2 и голосовая запись времени `21 30`. Другое время не подменяется временем известного факта.
- «Найти» отделено от «искать»; авторское «хотела найти» сохранено. Неизвестный получатель «мне» не отбрасывается как служебное слово.
- Версия проверяется по ограниченным связям предложений. Неправильный исполнитель, родительный падеж в «сестра Софии», пересказ чужой мысли и набор ключевых слов не открывают разгадку.
- Распознанные противоречия, в том числе несовершенный вид, «не София» и отрицание запуска компьютера, снимают соответствующее совпадение. Ответы на отрицательные вопросы остаются полными авторскими предложениями; голого двусмысленного «да» нет.

Файлы: `src/core/normalize.js`, `parseQuestion.js`, `state.js`, `solution.js`; `src/adapters/speech.js`; `tests/quality.test.mjs`, `tests/speech.test.mjs`; два браузерных проверочных скрипта. Обновлён README. Матрица `knownBy`, истинность десяти фактов, подсказки и сюжет не менялись.

## Воспроизведённые ошибки

Новые проверки запускались до исправлений. Среди фактических сбоев: уверенный ответ на перепутанных участников, неверный род местоимения, потерянная ссылка на старый ноутбук, неподдержанные формы А2 и время, принятие версии с другими исполнителями действий, «сестрой Софии» или игнорируемым отрицанием. Отдельный завершающий запуск новых трёх регрессий показал **3 FAIL**: подмена поиска нахождением, отрицание участника и отрицание запуска компьютера. После исправления все перечисленные регрессии проходят.

## Ограничения и следующий запрос

Открытых FAIL среди выполненных автоматических проверок нет. TODO выше остаются непроверенными или требуют подтверждённого контента. Свободная речь разбирается ограниченным локальным словарём: отсутствие совпадения даёт UNKNOWN и просьбу переформулировать, а не выдуманный факт. Это не универсальный анализ русского языка и не оценка произношения/грамматики.

Полная разгадка всё ещё не выводится самостоятельно из всех реплик: у выдачи ключа, родства и некоторых других деталей нет подтверждённых знаний свидетелей. Порог раскрытия сведений Софии не придуман. Технически подготовленный пользователь может прочитать solution в статическом JSON через DevTools; проверена защита от случайного показа интерфейсом, а не криптографическое сокрытие.

Следующий запрос: ручная проверка реального `ru-RU` на целевых устройствах; отдельно — согласование пробелов `docs/08_OPEN_ISSUES.md`, если требуется законченная доказуемая цепочка расследования. Эти этапы автоматически не запускались.

Локальный запуск: `node tools/serve.mjs`, адрес **http://127.0.0.1:8080**. Сервер оставлен работающим.
