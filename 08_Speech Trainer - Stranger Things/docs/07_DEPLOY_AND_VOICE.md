# Деплой и голос

## Рекомендация
Для демонстрации — статический GitHub Pages (HTTPs); Render и Timeweb Cloud не требуются, пока отсутствуют серверные функции. Сохранять относительные пути и, если сборщик присутствует, настраивать base path под имя репозитория. Не сменять уже работающий пайплайн до аудита в запросе №5.

## Речь
- Предпочтительно использовать браузерный `SpeechRecognition` / `webkitSpeechRecognition`, `lang='ru-RU'`.
- Начало прослушивания — по пользовательскому действию; остановка и ошибки понятны.
- Сервис распознавания может требовать соединения с сервером браузера и может быть недоступен в браузерах, сетях или регионах. Не обещать локального распознавания или гарантированной работы в РФ.
- После распознавания показывать текст в **редактируемом** поле. Движок обрабатывает **подтверждённый** вопрос, а не промежуточный текст.
- На отказ в доступе, пустую речь, отсутствие API — сообщить о проблеме, оставить ручной ввод.
- Не делать обязательный text-to-speech и не загружать аудио на собственный сервер.

## Privacy
Не запрашивать имя, адрес, почту студента; не отправлять реплики в сторонний сервис кроме встроенного распознавания браузера, если этот сервис используется и его политика известна. Не хранить стенограммы на сервере. Для публичного конкурса заранее сообщить пользователю, что голосовой ввод может использовать сервис браузера; обеспечить равный текстовый сценарий.

## Технические проверки
1. Локальный запуск по фактическому проекту (простой локальный HTTP-сервер, Vite — только если уже используется).
2. Чистый сеанс, Network без 404 на ES-модули/JSON, без исключений JS.
3. Проверить GitHub Pages с путём `/repository-name/` (или фактическим доменом) и HTTPS.
4. Открыть мобильный браузер без SpeechRecognition — пройти текстовую ветку.
5. На поддерживаемом браузере с микрофоном протестировать `ru-RU` несколькими фразами с А2 и правкой распознанного текста.

## Ограничение конфиденциальности разгадки
На статическом хостинге файл `case-001.json` может быть прочитан через инструменты браузера; это допустимо для демонстрационного MVP без античит-защиты. Нельзя заявлять, что секрет защищён от просмотра исходников.
