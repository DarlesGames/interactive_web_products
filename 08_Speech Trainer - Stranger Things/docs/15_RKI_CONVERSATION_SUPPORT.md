# Речевая опора для РКИ

## Изменено

По запросу пользователя добавлена помощь в построении диалога. Ранее ученик должен был сам угадать и сюжетный вопрос, и формулировку, которую понимает бот. Теперь панель «Помощь с вопросом» даёт речевую задачу и несколько уровней поддержки:

1. Цель: например, узнать у Ильи, кого он видел у входа.
2. Короткая языковая опора: «Кого» используем после «видел»: видел кого?
3. Начало фразы: «Кого…» — вставляется в пустой черновик для самостоятельного продолжения.
4. Сборка из грамматически совместимых частей: «Кого» + «вы видели» → «Кого вы видели?».
5. Полный пример по отдельному запросу. Его можно вставить, изменить или прочитать в микрофон.

В справке также есть фразы для начала разговора, повторения, продолжения темы, краткого обзора и благодарности. Бот понимает «Здравствуйте! Можно задать вам вопрос?» и «Спасибо за помощь» как служебные реплики.

Это добровольная опора; текстовый и голосовой ввод доступны постоянно. Ни одно действие панели не отправляет вопрос автоматически и не заменяет собственный черновик. Панель можно свернуть. После вставки фокус переходит к тексту. На мобильном панель раскрывается в странице, без вложенной прокрутки конструктора.

## Как выбирается помощь

В JSON истории добавлены 20 речевых задач. В них нет ответов свидетелей. Чистый модуль `src/core/conversationCoach.js` выбирает только задачи, для которых общий движок уже разрешает ответ текущего свидетеля. Учитываются `knownBy`, `revealPolicy`, реальные открытые факты, незавершённое уточнение и предложенная ботом тема. В UI передаётся только публичная учебная часть; служебные ID фактов, условия и ответы не передаются моделью панели.

Заданный вопрос и полученный факт убирают выполненную задачу. Смена свидетеля обновляет задачи и сохраняет черновик. Если здесь нет новых доступных фактов, показываются другие свидетели с доступными задачами. Нельзя открыть секрет простым просмотром панели. Отправленная собранная фраза идёт через обычный бот и общую проверку знаний; отдельного обходного маршрута нет.

Подсказки о русском языке не расходуют три сюжетные подсказки. Статистика меняется после отправки обычным способом. Оценка грамотности и произношения не добавлялась.

## Проверено

- 231 автоматический тест активного приложения — PASS; 0 FAIL, 0 SKIP.
- 122 архивных теста — PASS.
- Шесть браузерных сценариев: основной поток, чат-бот, выход из непонимания, новое расследование, голосовой адаптер и учебная опора — PASS на 360 и 1280 px.
- Все комбинации частей каждой речевой задачи проверены: движок отвечает по ожидаемому факту.
- Матрица свидетелей и условий проверена отдельно: преждевременные/чужие задачи не появляются; ответ убирает задачу; сброс возвращает начальные задачи.
- Сквозной тест проходит все доступные факты через опоры, без угадывания формулировок; браузерный тест получает основные четыре элемента через реальные кнопки помощи и ручную отправку.
- Проверены сохранность черновика, отсутствие отправки/новых баллов при просмотре и вставке, редактирование, смена свидетелей, помощь после ошибки и отсутствие спойлеров в начальной панели.
- Мобильный скриншот конструктора просмотрен. Локальный сервер доступен на `http://127.0.0.1:8080`.

## Ограничения

Сценарный бот по-прежнему понимает ограниченное число формулировок. Опоры дают гарантированно поддержанные способы вести разговор, но не являются универсальным анализом русского языка. Нужна дальнейшая ручная проверка с учениками РКИ: автоматические тесты подтверждают работу продукта, а не педагогическую эффективность. Физический микрофон не тестировался; голос проверен имитацией Web Speech API. Новых зависимостей, внешних API и изменений сюжета в этом этапе нет.
